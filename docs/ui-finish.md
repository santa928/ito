## 世界観と配置

木の卓上、麻布、クリーム色の紙、茶の縁、深緑の操作、朱色の注意表示。既存の基準画像とCSSによる素材表現を維持する。
ホームはタイトルと開始ボタン、ゲーム中はカードと現在の段階を中心にする。
操作は通常フローでカードや入力の近くに置く。スマホの外周を12px、紙面の内側を16pxから確保し、子要素の実寸で伸びる。画面比率でHUD位置を固定しない。
画像より文字が主役の既存UIを継承し、共有画像にも同じタイトル・色・文言を使用する。

## 非対象

採点方式の変更、オンライン対戦、アカウント、外部分析、音声、秘密の永続化、依存追加、フレームワーク刷新。
OSによる終了からのラウンド復元、物理端末の撮影・サムネイル防止は保証しない。

## リスクと検証

- 共通CSS・文字サイズが全画面の寸法へ影響するため、代表幅と両ブラウザの既存完走回帰を使う。
- focus/scroll変更が秘密確認とモーダルを妨げないことを、画面切替・再確認・終了取消で確認する。
- お題の変更/検索/undo/未保存確認は、画面上の操作から保存データを確認する回帰を追加する。
- メタデータはbuild後のHTMLと実画像、canonical/og:urlの一致を確認する。SNSサービスの実プレビューは公開後の別の証拠として扱う。

## 性能目標

ランタイム依存を追加しない。JS+CSS gzip増分は基準から10KiB以内を目安とし、余分な外部通信や待機アニメーションを追加しない。
検索は既存90件のローカルデータ内で完結する。通常操作に意図的な待ち時間を加えず、reduced-motionを尊重する。

## 検証結果

2026-09-13、開発コマンドはすべてDocker内で実施。

- unit: 95 passed。ルール・保存・秘密表示の既存契約を維持。lint・TypeScript/buildも成功。
- 最終本番buildでE2E: 35 passed (2.4m)、1 skipped。WebKitとChromiumの2/3/8人完走・再戦、秘密の解除、モーダル、設定復旧、検索・削除取消・入力保護・フォーカス・画像配信を確認。skipはChromium CDP専用のネイティブtouch検証のWebKit分。
- ホーム320/390/430pxで横overflowなし。開封直後の数字と操作がviewportに残ることを2/3/8人で確認。8人・24文字の同名では行の子要素が境界内に収まり、スクロールで順序が変わらない。
- Docker Chromiumで11画面状態を計測し、横overflow0、幅/高さ44px未満の可視button0、pageerror0。アプリ内ブラウザでも390pxの各画面と320pxホームを目視確認。端末フォントの差で見つかった1文字折返しと装飾の接近を修正。
- OGPは1200×630 PNG。Appleは180×180、PWAは既存SVGの図柄を192/512px PNG化し、実ファイルのPNG署名・寸法・配信type・manifestとの対応を両ブラウザで確認。画像自体も目視確認。
- 実SWで旧版→現行→次版の3世代を検証し、進行中と結果を保持、ホームに戻るだけでは再読み込みなし、明示した更新だけで1回再読み込みすることを確認。最終版の操作20回のp95は15.2ms、最大16.9ms（Docker Chromium・390×844・CPU制限なし、click受信→次rAF callback）。実機の描画時間や高速化の主張ではない。
- JS+CSS+SW gzipは89,841 bytes。旧版`e0b8e3c`の80,885 bytesから+8,956 bytesで、旧版から通算でも10KiB以内。前回公開の記録87,367 bytesに対しては+2,474 bytes。依存追加なし。
